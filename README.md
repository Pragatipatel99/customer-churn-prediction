# Customer Churn Prediction

An end-to-end machine learning project that predicts whether a telecom customer is likely to churn or stay with the company. The project covers data preprocessing, exploratory data analysis, feature engineering, machine learning model comparison, hyperparameter tuning, feature importance analysis, and Streamlit deployment.

## Project Objective

The goal of this project is to use historical customer data to predict whether a customer is likely to churn or stay with the company.

Customer churn prediction can help businesses identify high-risk customers and take proactive retention measures.

## Dataset

The project uses the Telco Customer Churn dataset.

### Dataset Details

- Number of customer records: 7,043
- Problem type: Binary Classification
- Target variable: `Churn`
- `Yes` = Customer churned
- `No` = Customer stayed

### Major Features

The dataset contains customer information related to:

- Demographics
- Customer tenure
- Phone services
- Internet services
- Online security
- Online backup
- Device protection
- Technical support
- Streaming services
- Contract type
- Payment method
- Monthly charges
- Total charges
